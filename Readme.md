# Vircon32: Web emulator

This is one of the GitHub repositories for Vircon32. This is a work in progress intended to create a web browser version of the emulator, based on the code of the desktop Vircon32 emulator.

This will be much less feature rich than the regular emulator, since it is meant to be embedded in sites such as itch.io, so that site users can try Vircon32 games directly from their game page.

----------------------------------
### What is removed here?

- The controls editor program.
- Any settings for a specific operating system.
- The ability to load and save settings: defaults are used.
- The ability to load and save controls: default keyboard keys are used.
- Support for savestates.
- Options to change screen size end go full screen.
- It can only load a cartridge from the command line.
- It can't load or use any memory card.
- It can't save screenshots.
